[核心特性]
1. 类型推断系统
   - 基础类型：自动推断 int, double, bool, char*
   - 特殊类型：识别 uint32_t 溢出模式（如 LCG 算法）
   - 混合运算：int 与 double 运算自动提升为 double
   - 作用域感知：函数内根据赋值自动更新变量类型记录

2. 变量与作用域管理 (Python 语义对齐)
   - 局部优先：函数内赋值默认创建局部变量，遮蔽同名全局变量
   - Global支持：支持 global 关键字显式修改全局变量
   - 参数重命名：自动检测参数与全局变量重名，生成 _arg_ 前缀避免 C 的 Shadow 警告

3. 数组/列表增强 (核心亮点)
   - 静态数组：全局/局部 list[int] 字面量 -> C 数组初始化
   - 长度自动管理：
     * 自动生成 <arr>_len 变量
     * len(arr) -> 编译期替换为长度变量
   - 隐式参数传递：
     * 函数定义自动追加长度形参 (int *arr -> int *arr, int n)
     * 函数调用自动补全长度实参 (call(arr) -> call(arr, arr_len))
   - 安全性：禁止 return 局部数组（防止悬垂指针）

4. 控制流
   - If/Elif/Else：完整支持
   - For 循环：支持 range(stop), range(start, stop), range(start, stop, step)
   - 负步长支持：自动识别 range(..., -1) 生成正确的大于/小于判断
   - While 循环：支持 break / continue

5. 函数系统
   - 自动原型：生成 C 函数前置声明，解决调用顺序问题
   - Main 隔离：用户定义的 def main() 自动重映射为 user_main()
   - 返回值推断：基于 return 语句自动推断函数返回类型 (int/void/double)

6. IO 与 字符串
   - 智能 Print：
     * 自动格式化：根据类型匹配 %d, %2f, %s
     * 数组打印：print(arr) 自动展开为 for 循环打印内容 [1 2 3]
     * 字符串转义：处理引号和反斜杠转义
   - 字符串常量：支持基础字符串传递

7. 运算符
   - 算术：+, -, *, /, %
   - 整除：// (FloorDiv) 映射为 floor() 实现 Python 语义
   - 比较：==, !=, <, <=, >, >=
   - 逻辑：and (&&), or (||), not (!)

下一步计划：
1.多维数组：

目前逻辑是 int *，仅支持一维数组。如果未来有图像处理需求，可能需要支持二维数组（arr[y][x] -> arr[y*w + x] 或二级指针）。

2.结构体 (Struct)：

目前无法处理 Python 的 class 或 namedtuple。如果需要处理复杂数据包（如 Point.x, Point.y），可以考虑将简单的 Python 类映射为 C struct。

3.字符串操作：

目前支持打印和传递字符串常量。C 语言处理字符串拼接（s1 + s2）非常麻烦，目前不支持是合理的，但如果未来有需求，可能需要引入一个简单的 string buffer 机制。

## 最新增强功能与发现

### 1. 专业级错误报告
- **现状:** 转译失败时现在可以精确显示 **错误行号** 和 **代码上下文**（带箭头标记）。
- **效果:** 用户无需猜测错误位置，大幅缩短调试时间。

### 2. 增强的类型推断与大数支持
- **十六进制地址识别:** 自动识别十六进制常量（如 `0x40010800`）为 `uint32_t` 类型。
- **大整数后缀:** 自动为 64 位整数添加 `LL` 后缀（如 `4294967296LL`），避免 C 编译器溢出报错。
- **全大写常量处理:** 优化了宏识别逻辑，用户定义的 `STATE_IDLE = 0` 等常量现在能被正确转译为 C 全局变量。

### 3. 数学库与复杂表达式支持
- **math 模块直接映射:** 现在可以直接调用 `math.sin`, `math.sqrt`, `math.pi` 等，转译器会自动将其映射为 C 标准库 `<math.h>` 里的函数和宏。
- **智能 abs() 处理:** 自动根据参数类型选择 `abs` (int) 或 `fabs` (double)。
- **幂运算支持:** 支持 `x ** y` 语法，自动转译为 `pow(x, y)`。
- **字符串相等性检查:** 支持使用 `==` 或 `!=` 比较字符串（基于 `strcmp` 实现），并支持了经典的 `if __name__ == "__main__":` 结构。

### 4. 革命性的语法支持
- **直接列表遍历 (For Iteration):** 完美支持 `for item in items:` 语法。转译器会自动结合元数据，将其转换为基于索引的高效 C 循环。
- **结构体字段智能推断:** 通过分析 `__init__` 赋值路径和构造函数调用点，自动判断结构体成员应为 `int` 还是 `double`。

## 发现的转译器限制（已通过最佳实践规避）

### 1. 结构体设计规范
- **限制:** 不同结构体不能包含完全相同的字段名（类型推断依赖字段唯一性）。
- **最佳实践:** 为不同结构体设计唯一的字段名（例如 `Rectangle` 使用 `width`/`height` 而非 `x`/`y`）。

### 2. 列表字面量限制
- **限制:** 列表字面量已支持 `int`, `float`, `str` 常量，但暂不支持在字面量内嵌套函数调用。
- **最佳实践:** 对于需要函数生成的值，先声明数组，再在循环或逻辑中赋值。

### 3. 返回局部数组
- **限制:** C 语言不支持安全地返回栈上的局部数组。
- **最佳实践:** 将输出数组作为参数传递给函数，由调用者负责内存分配。

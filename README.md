2. **代码注释规范：**

 **1. 函数注释规范**

函数头部注释统一使用 `/** ... */` 格式，推荐模板如下：

```
/**
 * @brief  函数功能简述（不超过 1 行）
 * @details 函数详细描述（可多行）
 *          - 说明该函数做了什么
 *          - 使用了哪些关键算法或步骤
 *          - 有哪些注意事项
 *
 * @param param1 参数1说明
 * @param param2 参数2说明
 *
 * @return 返回值含义（若无返回可删除）
 *
 * @note  特殊说明，如线程安全、锁机制、性能警告等
 * @warning 高风险操作时必须使用，提示使用者注意
 */
```

例如：

```
/**
 * @brief 槽函数：示例——查找圆心按钮
 * @details 功能流程：
 *          - 从当前帧缓存 m_frameBuffer 构建灰度图
 *          - 使用高斯模糊 + HoughCircles 进行圆检测
 *          - 若检测到至少一个圆，取第一个：
 *              • 在 labelCircleCenter / labelCircleRadius 显示圆心坐标与半径
 *              • 在画布上绘制圆与圆心，并弹窗展示检测结果
 *          - 若未检测到圆，弹出提示框
 *
 * @note 使用 QMutexLocker 保护 m_frameBuffer/m_frameInfo/m_hasFrame，
 *       避免与图像回调线程竞争
 */
```

 ✅ **2. 类注释规范**

```

 * @details 类的主要功能、典型用途、线程模型、数据关系等

 * @note 可用于复杂逻辑的补充说明
 */
```

 ✅ **3. 变量 / 成员注释规范**

### 单行成员变量注释：


### 多行：

```
QString m_frameInfo;  ///< 当前帧的描述信息
```
